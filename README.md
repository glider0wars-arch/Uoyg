# VERDA 3D Product Story

A responsive, single-page product concept featuring an interactive Three.js can.

## Run locally
This page imports Three.js from jsDelivr, so it needs an internet connection. Serve the folder over HTTP, for example:

```bash
python -m http.server 8000
```

Open http://localhost:8000. Scroll through the story to rotate/reposition the can, or drag horizontally to rotate it manually.

## Notes
- VERDA is a fictional brand concept.
- The can, label texture, metal lid, pull tab, and condensation details are generated in code.
- No e-commerce or authentication backend is included.
